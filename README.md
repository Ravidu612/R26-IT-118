# R26-IT-118 – AI-Based Tea Estate Monitoring System

## 📌 Project Overview

This project focuses on developing an AI-based system to improve decision-making in tea estates. The system uses a trained YOLO (You Only Look Once) model to detect and analyze tea leaf conditions from images.

The goal is to assist estate managers in identifying issues such as leaf diseases and optimizing plantation management.

---

## 🚀 Features

* Image-based detection using YOLO model
* Upload image and get detection results
* Deployed AI model using Hugging Face Spaces
* Real-time prediction output

---

## 🧠 Technologies Used

* Python
* YOLO (Ultralytics)
* Hugging Face Spaces
* Gradio (for UI)

---

## ⚙️ How to Run the Project

1. Clone the repository
2. Install dependencies:
   ```bash
   pip install -r YOLO/requirements.txt
   ```
3. Place your trained YOLO weights at `YOLO/best.pt`.
4. Run the application:
   ```bash
   python YOLO/app.py
   ```
5. Open the local URL to access the interface
